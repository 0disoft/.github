# Código de conducta

Idioma: [English](../../../CODE_OF_CONDUCT.md) | [한국어](../ko/CODE_OF_CONDUCT.md) | Español | [简体中文](../zh-CN/CODE_OF_CONDUCT.md) | [हिन्दी](../hi/CODE_OF_CONDUCT.md) | [Français](../fr/CODE_OF_CONDUCT.md)

Este es el código de conducta predeterminado para los repositorios propiedad de 0disoft. Si un repositorio tiene su propio `CODE_OF_CONDUCT.md`, tendrá prioridad el código de conducta específico de ese repositorio.

## Comportamiento esperado

Se espera que las personas participantes:

- actúen con respeto y de forma constructiva
- asuman buena intención, sin dejar de hacerse responsables del impacto de sus palabras y acciones
- centren las críticas en las ideas, el código, la documentación y las decisiones del proyecto
- respeten el tiempo de los mantenedores y los límites del proyecto
- ayuden a mantener conversaciones útiles para quienes participan ahora y para quienes las lean más adelante

## Comportamiento no aceptable

No se aceptan los siguientes comportamientos:

- acoso, amenazas o ataques personales
- lenguaje o conducta discriminatoria
- comentarios o imágenes de carácter sexual
- interrupción deliberada de las conversaciones
- publicación de información privada sin permiso
- insistir repetidamente en una petición después de que un mantenedor haya tomado una decisión

## Alcance

Este código de conducta se aplica a las conversaciones del repositorio, issues, pull requests, canales de comunicación del proyecto y cualquier situación en la que una persona actúe en representación del proyecto.

## Aplicación

Los mantenedores pueden eliminar contenido, cerrar issues, rechazar pull requests, limitar la participación o bloquear usuarios cuando una conducta perjudique al proyecto o a su comunidad.

Las denuncias deben enviarse al mantenedor del repositorio. Si el repositorio ofrece un canal privado para reportes, utiliza ese canal.

Las denuncias se revisarán de buena fe. Los mantenedores darán prioridad a la seguridad y la privacidad de las personas involucradas.

## Atribución

Este código de conducta está inspirado en estándares comunes de comunidades de código abierto, incluido Contributor Covenant.
