# 支持指南

语言: [English](../../../SUPPORT.md) | [한국어](../ko/SUPPORT.md) | [Español](../es/SUPPORT.md) | [Français](../fr/SUPPORT.md) | [हिन्दी](../hi/SUPPORT.md) | 简体中文

这是适用于 0disoft 所有仓库的默认支持指南。如果某个仓库有自己的 `SUPPORT.md`，则以该仓库的专用支持指南为准。

## 寻求帮助之前

请先查看仓库的 README、文档和现有 issues。

## 在哪里提问

请根据具体情况选择最合适的渠道：

- Bugs：请创建 GitHub issue，并附上复现步骤。
- 功能请求：请创建 GitHub issue，说明要解决的问题和期望的结果。
- 使用问题：如果仓库启用了 GitHub Discussions，请使用该功能。
- 文档问题：请创建 GitHub issue 或提交 pull request。
- 安全漏洞：请按照 `SECURITY.md` 中的说明处理。

## 需要包含的信息

寻求帮助时，请包含以下信息：

- 你正在尝试做什么
- 你期望发生什么
- 实际发生了什么
- 复现问题的步骤
- 相关日志、截图、版本信息或运行环境细节

## 不在支持范围内的内容

维护者可能无法提供以下支持：

- 私人咨询
- 紧急生产环境支持
- 与项目无关的第三方代码调试
- 对修改版或不受支持版本的支持
- 对已归档或实验性仓库的支持

支持会在力所能及的范围内提供。
