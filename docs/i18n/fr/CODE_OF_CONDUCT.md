# Code de conduite

Langue : [English](../../../CODE_OF_CONDUCT.md) | [한국어](../ko/CODE_OF_CONDUCT.md) | [Español](../es/CODE_OF_CONDUCT.md) | [简体中文](../zh-CN/CODE_OF_CONDUCT.md) | [हिन्दी](../hi/CODE_OF_CONDUCT.md) | Français

Ce document constitue le code de conduite par défaut des dépôts appartenant à 0disoft. Si un dépôt possède son propre `CODE_OF_CONDUCT.md`, le code de conduite propre à ce dépôt prévaut.

## Comportement attendu

Les personnes participantes sont invitées à :

- faire preuve de respect et contribuer de manière constructive
- présumer la bonne intention des autres, tout en assumant l’impact de leurs propres paroles et actions
- concentrer les critiques sur les idées, le code, la documentation et les décisions du projet
- respecter le temps des mainteneurs ainsi que les limites du projet
- aider à maintenir des échanges utiles, aussi bien pour les participants actuels que pour les personnes qui les liront plus tard

## Comportement inacceptable

Les comportements suivants ne sont pas acceptés :

- harcèlement, menaces ou attaques personnelles
- langage ou comportement discriminatoire
- commentaires ou images à caractère sexuel
- perturbation volontaire des discussions
- publication d’informations privées sans autorisation
- demandes répétées après qu’un mainteneur a déjà pris une décision

## Champ d’application

Ce code de conduite s’applique aux discussions du dépôt, aux issues, aux pull requests, aux canaux de communication du projet, ainsi qu’à toute situation dans laquelle une personne représente le projet.

## Application

Les mainteneurs peuvent supprimer du contenu, fermer des issues, refuser des pull requests, limiter la participation ou bloquer des utilisateurs lorsqu’un comportement nuit au projet ou à sa communauté.

Les signalements doivent être envoyés au mainteneur du dépôt. Si le dépôt propose un canal de signalement privé, utilisez ce canal.

Les signalements seront examinés de bonne foi. Les mainteneurs donneront la priorité à la sécurité et à la confidentialité des personnes concernées.

## Attribution

Ce code de conduite s’inspire des standards courants des communautés open source, notamment du Contributor Covenant.
