# Guide de support

Langue : [English](../../../SUPPORT.md) | [한국어](../ko/SUPPORT.md) | [Español](../es/SUPPORT.md) | Français | [हिन्दी](../hi/SUPPORT.md) | [简体中文](../zh-CN/SUPPORT.md)

Ce document constitue le guide de support par défaut des dépôts appartenant à 0disoft. Si un dépôt possède son propre `SUPPORT.md`, le guide de support propre à ce dépôt prévaut.

## Avant de demander de l’aide

Consultez d’abord le README du dépôt, la documentation et les issues existantes.

## Où poser une question

Utilisez le canal le plus adapté à votre situation :

- Bugs : ouvrez une issue GitHub avec les étapes permettant de reproduire le problème.
- Demandes de fonctionnalités : ouvrez une issue GitHub en décrivant le problème et le résultat attendu.
- Questions d’utilisation : utilisez GitHub Discussions si le dépôt a activé cette fonctionnalité.
- Problèmes de documentation : ouvrez une issue GitHub ou envoyez une pull request.
- Vulnérabilités de sécurité : suivez les instructions de `SECURITY.md`.

## Informations à inclure

Lorsque vous demandez de l’aide, incluez :

- ce que vous essayez de faire
- ce que vous pensiez voir se produire
- ce qui s’est réellement produit
- les étapes permettant de reproduire le problème
- les logs, captures d’écran, versions ou détails d’environnement pertinents

## Ce qui n’est pas couvert

Les mainteneurs peuvent ne pas être en mesure de fournir :

- du conseil privé
- du support urgent pour un environnement de production
- du débogage pour du code tiers sans rapport avec le projet
- du support pour des versions modifiées ou non prises en charge
- du support pour des dépôts archivés ou expérimentaux

Le support est fourni dans la mesure du possible.
