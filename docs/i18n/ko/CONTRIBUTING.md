# 기여 안내

언어: [English](../../../CONTRIBUTING.md) | 한국어 | [Español](../es/CONTRIBUTING.md) | [Français](../fr/CONTRIBUTING.md) | [हिन्दी](../hi/CONTRIBUTING.md) | [简体中文](../zh-CN/CONTRIBUTING.md)

0disoft 프로젝트에 기여를 검토해 주셔서 감사합니다.

이 문서는 0disoft가 소유한 저장소에 기본으로 적용되는 기여 안내입니다. 각 저장소에 별도의 `CONTRIBUTING.md`가 있다면, 해당 저장소의 안내가 우선 적용됩니다.

## 기여하기 전에

새 이슈나 풀 리퀘스트를 열기 전에 저장소의 README, 기존 이슈, 기존 풀 리퀘스트를 먼저 확인해 주세요.

변경 범위가 큰 작업이라면 구현을 시작하기 전에 먼저 이슈를 열어, 작업 범위와 방향을 논의해 주세요.

보안 취약점은 공개 이슈로 올리지 마세요. 대신 `SECURITY.md`의 안내를 따라 주세요.

## 이슈

이슈는 다음과 같은 경우에 사용해 주세요.

- 재현 가능한 버그
- 범위가 명확한 기능 요청
- 문서 관련 문제
- 다른 사용자에게도 도움이 될 수 있는 프로젝트별 질문

이슈를 열 때는 다음 내용을 포함해 주세요.

- 기대했던 동작
- 실제로 발생한 동작
- 문제를 재현하는 절차가 있다면 해당 절차
- 관련 로그, 스크린샷, 버전, 실행 환경 정보

각 이슈는 하나의 문제나 요청에 집중해 주세요.

## 풀 리퀘스트

범위가 명확하고 검토하기 쉬운 풀 리퀘스트는 언제든 환영합니다.

풀 리퀘스트를 열기 전에 다음 사항을 확인해 주세요.

- 변경 범위를 가능한 한 작게 유지합니다.
- 이 변경이 필요한 이유를 설명합니다.
- 필요한 경우 테스트나 문서를 함께 추가합니다.
- 관련 없는 리팩터링은 피합니다.
- 저장소별 안내가 있다면 해당 지침을 따릅니다.

프로젝트 범위를 벗어나거나, 안전하게 검토하기에는 범위가 너무 넓거나, 저장소의 방향과 맞지 않는 풀 리퀘스트는 거절될 수 있습니다.

## 저장소별 안내

빌드 명령어, 테스트 명령어, 릴리스 규칙, 아키텍처 메모, 의존성 정책, 배포 안내는 각 저장소의 README 또는 저장소별 `CONTRIBUTING.md`에 작성해 주세요.
