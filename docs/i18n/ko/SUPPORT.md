# 지원 안내

언어: [English](../../../SUPPORT.md) | 한국어 | [Español](../es/SUPPORT.md) | [Français](../fr/SUPPORT.md) | [हिन्दी](../hi/SUPPORT.md) | [简体中文](../zh-CN/SUPPORT.md)

이 문서는 0disoft가 소유한 저장소에 기본으로 적용되는 지원 안내입니다. 각 저장소에 별도의 `SUPPORT.md`가 있다면, 해당 저장소의 지원 안내가 우선 적용됩니다.

## 도움을 요청하기 전에

먼저 저장소의 README, 문서, 기존 이슈를 확인해 주세요.

## 문의할 곳

상황에 맞는 채널을 사용해 주세요.

- 버그: 재현 절차를 포함해 GitHub 이슈를 열어 주세요.
- 기능 요청: 해결하려는 문제와 기대하는 결과를 설명해 GitHub 이슈를 열어 주세요.
- 사용 방법 질문: 저장소에서 GitHub Discussions를 사용하고 있다면 해당 기능을 이용해 주세요.
- 문서 문제: GitHub 이슈를 열거나 풀 리퀘스트를 보내 주세요.
- 보안 취약점: `SECURITY.md`의 안내를 따라 주세요.

## 포함해야 할 내용

도움을 요청할 때는 다음 내용을 포함해 주세요.

- 하려는 작업
- 기대했던 동작
- 실제로 발생한 동작
- 문제를 재현하는 절차
- 관련 로그, 스크린샷, 버전, 실행 환경 정보

## 지원하지 않는 범위

메인테이너는 다음 항목에 대해 지원을 제공하지 못할 수 있습니다.

- 비공개 컨설팅
- 긴급 운영 환경 지원
- 프로젝트와 직접 관련 없는 외부 코드 디버깅
- 수정된 버전 또는 지원 대상이 아닌 버전에 대한 지원
- 보관 처리된 저장소 또는 실험용 저장소에 대한 지원

지원은 가능한 범위 내에서 제공됩니다.
