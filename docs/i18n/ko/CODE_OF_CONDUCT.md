# 행동 강령

언어: [English](../../../CODE_OF_CONDUCT.md) | 한국어 | [Español](../es/CODE_OF_CONDUCT.md) | [简体中文](../zh-CN/CODE_OF_CONDUCT.md) | [हिन्दी](../hi/CODE_OF_CONDUCT.md) | [Français](../fr/CODE_OF_CONDUCT.md)

이 문서는 0disoft가 소유한 저장소에 기본으로 적용되는 행동 강령입니다. 각 저장소에 별도의 `CODE_OF_CONDUCT.md`가 있다면, 해당 저장소의 행동 강령이 우선 적용됩니다.

## 기대하는 행동

참여자는 다음 기준을 따라야 합니다.

- 서로 존중하며 건설적으로 소통합니다.
- 선의를 전제로 하되, 자신의 말과 행동이 만든 영향에 책임을 집니다.
- 비판은 사람에게 향하지 않고 아이디어, 코드, 문서, 프로젝트 결정에 초점을 맞춥니다.
- 메인테이너의 시간과 프로젝트의 경계를 존중합니다.
- 현재 참여자뿐 아니라 나중에 읽을 사람에게도 도움이 되는 논의를 지향합니다.

## 허용되지 않는 행동

다음 행동은 허용되지 않습니다.

- 괴롭힘, 협박, 인신공격
- 차별적인 언어 또는 행동
- 성적인 발언이나 이미지
- 논의를 의도적으로 방해하는 행위
- 허가 없이 타인의 개인정보를 공개하는 행위
- 메인테이너가 결정을 내린 뒤에도 같은 요구를 반복하는 행위

## 적용 범위

이 행동 강령은 저장소의 토론, 이슈, 풀 리퀘스트, 프로젝트 관련 커뮤니케이션 채널, 그리고 누군가가 프로젝트를 대표하는 상황 전반에 적용됩니다.

## 집행

메인테이너는 프로젝트나 커뮤니티에 해가 되는 행동이 있을 경우 콘텐츠 삭제, 이슈 종료, 풀 리퀘스트 거절, 참여 제한, 사용자 차단 등의 조치를 취할 수 있습니다.

신고는 해당 저장소의 메인테이너에게 보내면 됩니다. 저장소에서 비공개 신고 채널을 제공하는 경우, 해당 채널을 사용해 주세요.

신고는 선의에 따라 검토되며, 메인테이너는 관련된 사람들의 안전과 개인정보 보호를 우선합니다.

## 출처

이 행동 강령은 Contributor Covenant를 포함한 일반적인 오픈소스 커뮤니티 기준을 참고해 작성되었습니다.
