# सहायता मार्गदर्शिका

भाषा: [English](../../../SUPPORT.md) | [한국어](../ko/SUPPORT.md) | [Español](../es/SUPPORT.md) | [Français](../fr/SUPPORT.md) | हिन्दी | [简体中文](../zh-CN/SUPPORT.md)

यह 0disoft के स्वामित्व वाले रिपॉज़िटरी के लिए डिफ़ॉल्ट सहायता मार्गदर्शिका है। यदि किसी रिपॉज़िटरी में अपना `SUPPORT.md` है, तो उसी रिपॉज़िटरी की सहायता मार्गदर्शिका को प्राथमिकता दी जाएगी।

## मदद मांगने से पहले

कृपया पहले रिपॉज़िटरी का README, documentation और मौजूदा issues देख लें।

## कहाँ पूछें

स्थिति के अनुसार सबसे उपयुक्त चैनल का उपयोग करें:

- Bugs: समस्या को दोहराने के चरणों के साथ GitHub issue खोलें।
- Feature requests: समस्या और अपेक्षित परिणाम का वर्णन करते हुए GitHub issue खोलें।
- Usage questions: यदि रिपॉज़िटरी में GitHub Discussions enabled है, तो उसका उपयोग करें।
- Documentation problems: GitHub issue खोलें या pull request भेजें।
- Security vulnerabilities: `SECURITY.md` का पालन करें।

## क्या शामिल करें

मदद मांगते समय ये जानकारी शामिल करें:

- आप क्या करने की कोशिश कर रहे हैं
- आपको क्या होने की अपेक्षा थी
- वास्तव में क्या हुआ
- समस्या को दोहराने के चरण
- संबंधित logs, screenshots, versions या environment details

## क्या शामिल नहीं है

मेंटेनर निम्नलिखित सहायता देने में सक्षम न भी हो सकते हैं:

- निजी परामर्श
- production environment के लिए तत्काल सहायता
- परियोजना से असंबंधित third-party code की debugging
- modified या unsupported versions के लिए सहायता
- archived या experimental रिपॉज़िटरी के लिए सहायता

सहायता उपलब्ध क्षमता के अनुसार प्रदान की जाती है।
