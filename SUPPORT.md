This is the default support guide for repositories owned by 0disoft. If a repository has its own `SUPPORT.md`, the repository-specific support guide takes precedence.

## Before Asking for Help

Please check the repository README, documentation, and existing issues first.

## Where to Ask

Use the most appropriate channel:

- Bugs: open a GitHub issue with reproduction steps.
- Feature requests: open a GitHub issue describing the problem and proposed outcome.
- Usage questions: use GitHub Discussions if the repository has Discussions enabled.
- Documentation problems: open a GitHub issue or pull request.
- Security vulnerabilities: follow `SECURITY.md`.

## What to Include

When asking for help, include:

- what you are trying to do
- what you expected to happen
- what actually happened
- steps to reproduce the problem
- relevant logs, screenshots, versions, or environment details

## What Is Not Covered

Maintainers may not be able to provide:

- private consulting
- urgent production support
- debugging for unrelated third-party code
- support for modified or unsupported versions
- support for archived or experimental repositories

Support is provided on a best-effort basis.
